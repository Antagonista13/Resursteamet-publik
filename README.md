# Förhandsgranskning av Resursteamet Dashboard

Endast testdata. Fristående kopia från utvecklingsgrenen, commit `a44242f1def4c09b9dbf5e52b99cf0100fdd4322`.
Inga produktionsfiler eller produktionsinställningar har ändrats.

1. Hämta [ZIP-filen](resursteamet-dashboard-test.zip?raw=1).
2. Packa upp den.
3. Öppna `resursteamet-dashboard-test.html` i din webbläsare.

Prova Dag, Vecka, personalens statusval, Redigera testdata och Storbildsläge (TV).
Väder, matsedel, lov och all person-/ärendeinformation är påhittade testdata.
Ingen SharePoint-/Outlook-anslutning eller extern datahämtning används.
Kalenderdata lagras enbart under en separat nyckel för förhandsgranskningen.
Personal- och ärendeändringar återställs vid omladdning.

Om din organisations webbläsare blockerar lokala HTML-filer behöver den öppnas i en tillåten testmiljö; ändra inte organisationens policy som del av detta test.
